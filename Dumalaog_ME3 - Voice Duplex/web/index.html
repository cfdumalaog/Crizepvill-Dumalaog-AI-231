ME3 Voice Duplex

A no-training, interruptible voice agent that listens, reasons with Qwen, calls bounded tools, and speaks through Piper or ElevenLabs.

Presentable release

Voice and tool pipeline

Owned MCP services keep speech and task execution explicit. A web request can build a real artifact; it is not only an explanatory model response.

Microphone / injected PCM→ Silero VAD→ Whisper ASR→ Qwen + MCP tools→ Piper / ElevenLabs→ Speaker

Workstation gate

Windows is the finalization and presentation environment. The exact accepted release is promoted to the Pi only after tests, artifact checks, audio smoke, and package hashing pass.

Agentic tasks

Voice or text can ask ME3 to create a web app, write files, run bounded commands, start a local server, inspect the result, and report the URL.

Hardware gate

The Pi software release is deployed, but physical voice service remains disabled until a capture device is visible to ALSA and PortAudio.

Communication layer

Confirmed Twilio calls/SMS and Resend email are implemented behind protected credentials. Live provider tests remain operator-controlled.

Local agent console

Run Start-ME3-UI.bat to open the interactive workstation UI at 127.0.0.1:8124. It exercises Qwen and project tools while blocking external channels.

Browser scope: this is a private local/LAN presenter surface. Windows uses 127.0.0.1:8123; the ME2-style Pi SSH tunnel uses 127.0.0.1:8090. Neither URL publishes ME3 to the public Internet.
